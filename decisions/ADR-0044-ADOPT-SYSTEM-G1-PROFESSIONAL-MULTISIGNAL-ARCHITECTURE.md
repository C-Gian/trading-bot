## System G1

Authorize one bounded functional/research generation, `SYSTEM_G1`, consisting of:

- one local BTC web product;
- continuous 15m prediction snapshots;
- a 4h terminal-return forecast target;
- selective LONG / SHORT / NO_TRADE paper decisions;
- shared 1m/1h/4h/daily/weekly/monthly state as declared;
- one six-scale cycle family;
- exactly two initial playbooks;
- one native bidirectional reference-paper ledger;
- one causal historical replay/live core;
- at most seven predeclared historical development configurations;
- at most one later prospective system if promotion gates are earned.

No open-ended source ladder, indicator tournament, model tournament, timeframe tournament or
autonomous AI alpha generation is authorized.

## Initial playbooks

Registered:

1. `SYSTEM-G1-P1-DIRECTIONAL-CONTINUATION`
2. `SYSTEM-G1-P2-FAILED-AUCTION-REENTRY`

No third G1 playbook is allocated.

## Scientific role of components

A signal/component is not required to demonstrate standalone profitable alpha merely to serve a
predeclared contextual/corroborative/risk role in a coherent playbook.

Every active component must still have:

- a declared role;
- causal availability;
- deterministic definition;
- controlled removal/comparison semantics;
- complexity accountability.

This rule does not permit arbitrary feature accumulation.

## Time and cycle architecture

Freeze the System G1 architectural clocks:

- canonical source/execution: 1m;
- decision / continuous-prediction clock: completed 15m;
- primary terminal forecast: 4h;
- structure: 1h;
- directional regime: 4h;
- completed daily context;
- weekly/monthly background;
- cycle scales: 45m, 3h, 1d, 4d, 1w, 4w.

No alternative clock/horizon tournament is authorized.

Cycle method family is frozen separately in
`research/protocols/SYSTEM-G1-CYCLE-METHOD-V1.md` and must pass synthetic method validation before it
can affect a G1 decision.

## Paper reference system

For a coherent bidirectional laboratory, System G1 uses BTCUSDT USD-M traded prices as the reference
paper execution instrument for LONG and SHORT. BTC spot remains a separately identified information
source.

This is not an Owner authorization to use futures, margin, leverage, credentials or real capital.
Virtual gross exposure is capped at 1x equity.
