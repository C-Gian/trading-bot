# Cycle Research Source Boundary V1

Status: CANONICAL. Applies to all project references to Ciclica Evoluta / Analisi
Evoluta and to every cycle-research implementation derived from those concepts.

## Classification contract

- `DOCUMENTED_PUBLIC`: conceptual material the project may describe as present in the
  public Ciclica Evoluta / Analisi Evoluta corpus.
- `RECONSTRUCTED`: an explicit, reproducible project choice designed to operationalize
  a concept. It must be attributed to this project, never presented as Marini's official
  or universal method.
- `UNSPECIFIED`: the public corpus does not supply a complete, universal, executable
  rule at the granularity needed by this project. The project must not fill the gap by
  implication or attribution.

`DOCUMENTED_PUBLIC` identifies conceptual provenance, not empirical support, a frozen
algorithm, or permission to implement a trading component.

## RECONSTRUCTED project work

Any centering, swing selection/value, threshold, inverse, vincolo, raccordo, target,
spectral, phase, null-generation, or multi-timeframe rule invented or completed by this
project is `RECONSTRUCTED`. Its record must state the project version, rationale,
parameters, causal information boundary, and validation status. Similarity to a public
concept does not change its classification.

P2 uses only a project-reconstructed statistical representation of time structure. It
does not claim to implement the Ciclica Evoluta methodology. No swing, volume, inverse,
vincolo, raccordo, target, or cycle-based trading implementation exists or is authorized
at this checkpoint.
