# Prospective build semantic manifest closure V1_1

Research Director acceptance of `PROSPECTIVE-RUNTIME-ARTIFACT-PROVENANCE-FIX-V1_1` is
recorded. Runtime health and evidence stores no longer dirty the scientific build, the
missed `2026-09-16T13:00Z` boundary remains permanently missed, nothing was backfilled,
and genuine prospective observations remain zero.

`BUILD_PROVENANCE_V1` identified a build from an incomplete manifest: it covered the
observer, analysis, continuation, causal execution engine, governed cost implementation
and the evidence contract, but not the modules that decide the feature adapter, the live
bar semantics, admissibility, evidence integrity, single-observer ownership, durability
primitives, or the observer lifecycle. A change to any of those could have altered what
an observation meant without moving its identity.

`BUILD_PROVENANCE_V1_1` freezes a fifteen-member bounded closure: the observer
application wiring, the product package version, analysis, prospective features and
continuation, the public market feed, the causal execution engine, the observer itself,
provenance, the audit chain, the observer lease, the durable file-io primitives, the two
cost sources resolved from the objects actually imported, and the evidence contract.
Frontend, governance and reporting files are deliberately excluded because none of them
can change the signal, live input, execution, costs, admissibility, integrity or
lifecycle. `BUILD_PROVENANCE_V1` is `SUPERSEDED_BEFORE_FIRST_REAL_OBSERVATION`.

Evidence remains `FUTURE_SHADOW_PAPER_EVIDENCE_V1_1`. It has produced zero genuine
observations and its store does not exist, so no migration is required; the contract is
updated only to require the new provenance version.

The member set is pinned in the state contract and in tests, so a member cannot silently
disappear. Every member is proven identity-sensitive: altering any one moves the
aggregate SHA256 to a distinct value, dropping any one moves it, and the provenance
version itself binds the aggregate. Identity therefore does not rest on `git HEAD`, which
continues to be recorded alongside branch and clean-worktree status.

The accepted runtime-artifact rule is preserved: generated `data/paper/` state never
alters semantic identity or the clean-worktree verdict. It is now also bounded from the
other side, because a frozen manifest member is never exempted from that verdict whatever
runtime path rules apply, and arbitrary tracked source, configuration and governance
changes outside the runtime directory still make the build unverified.

Operational health history is untouched and the missed boundary is not rewritten.
Restarting collection may create `BACKEND_DOWNTIME` missed records for elapsed
boundaries; that is expected and truthful.

Collection is restored to `ARMED_NOT_YET_OBSERVED` with the review boundary at 20
completed automated shadow trades and no result-driven adaptation before it. Validation
was synthetic; the production observer was not started, live market data was not
contacted, and no genuine observation was created. Historical accounting remains 26
experiments, 12 observed material historical hypotheses, zero sealed queries, Champion
`NONE`, and real money false.
